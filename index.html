GET /swaphistory
↑
Retrieve Swap History (swaphistoryGet)
Fetch aggregated swap metrics and interval-based data for a specified pool.

Query Parameters

pool (required)
Query Parameter — Pool name (e.g., BTC.BTC, ETH.ETH)
from (optional)
Query Parameter — Start timestamp (Unix). Default: 1577836800
to (optional)
Query Parameter — End timestamp (Unix). Default: 1893455999
interval (optional)
Query Parameter — Aggregation interval (hour, day, week, month, year). Default: hour
limit (optional)
Query Parameter — Max records. Default: 50
offset (optional)
Query Parameter — Records to skip. Default: 0
